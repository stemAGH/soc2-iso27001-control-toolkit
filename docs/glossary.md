# Glossary

| Term | Meaning in this toolkit |
| --- | --- |
| SOC 2 | Independent CPA examination/report using applicable Trust Services Criteria; not a product certification |
| Trust Services Criteria (TSC) | Criteria used to evaluate controls supporting service commitments and system requirements |
| Common Criteria (CC) | SOC 2 criteria including control environment, access, operations, change and other areas; not ISO Annex A |
| Type 1 / Type 2 | SOC 2 design assessment at a specified date / design and operating-effectiveness assessment over a specified period, with applicable reporting requirements |
| ISO/IEC 27001 | Requirements standard for an information security management system |
| ISO/IEC 27002 | Implementation guidance for information security controls; distinct from ISO/IEC 27001 certification requirements |
| ISMS | Information security management system covering governance, risk, operations and improvement |
| Annex A | ISO/IEC 27001 reference controls considered during risk treatment; not an automatic checklist of universally required implementations |
| Statement of Applicability (SoA) | Necessary controls with inclusion reasons, implementation status and justified Annex A exclusions |
| Control / criterion | Organization-specific activity or mechanism / benchmark against which controls are assessed |
| Direct / Partial mapping | Author-assessed objective alignment / supporting overlap; neither proves compliance |
| Evidence | Scoped, attributable records used to assess an assertion about a control |
| Population / sample | Complete set of relevant items / selected items tested from that set |
| Design / operating effectiveness | Ability of a control to address its objective / whether it actually operated as intended over the assessed period |
| Inherent / residual risk | Exposure before controls / current exposure after existing controls |
| Risk acceptance | Authorized, time-bound decision to retain defined risk; not a waiver of law or contract |
| Least privilege / segregation of duties | Minimum necessary rights / division of incompatible responsibilities |
| IAM / AD / GPO | Identity and access management / Active Directory / Group Policy Object |
| SIEM / Wazuh | Security information and event management / monitoring platform used in the proposed design |
| EDR / XDR | Endpoint detection and response / extended detection and response; features vary by license and product |
| CloudTrail / Config | AWS API activity logging / supported resource configuration recording and evaluation |
| Event / incident | Observable occurrence / occurrence assessed as requiring incident response based on impact or potential impact |
| RTO / RPO | Target restoration time / acceptable data-loss interval measured in time |
| Chain of custody | Documented acquisition, handling, transfers and disposition of evidence |
| Hash / provenance | Integrity digest relative to a baseline / evidence of origin and handling; a hash alone is not provenance |
| Shared responsibility | Distribution of provider and customer security obligations for the particular service |
