# Test execution record — blank reusable form

| Field | Entry |
| --- | --- |
| Test ID and control ID; design or operating test | To be completed |
| Tester, independent reviewer and execution date | To be completed |
| Scope, period, timezone and control owner | To be completed |
| Source query, full population count and completeness reconciliation | To be completed |
| Sample IDs, selection method, size and rationale | To be completed |
| Procedure, expected results and negative cases | To be completed |
| Evidence IDs, provenance, collection errors and limitations | To be completed |
| Observations and exceptions | To be completed |
| Pass, Fail or Not tested; basis and affected framework requirements | To be completed |
| Remediation owner, ticket, due date and verified retest | To be completed |
| Reviewer approval and date | To be completed |

Pass requires every stated condition to be evidenced. Missing evidence is Not tested unless an actual exception
is observed, in which case record Fail. Neither is a passing control. Do not erase original failed tests after retesting.
